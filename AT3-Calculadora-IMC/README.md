# AT3 — Calculadora de IMC

## Descrição
Calculadora de Índice de Massa Corporal para adultos, entregue originalmente no arquivo `Calculadora de IMC.zip`.

## Funcionalidades
- Entrada de peso em quilogramas e altura em metros ou centímetros.
- Aceita vírgula ou ponto como separador decimal.
- Valida os valores informados.
- Calcula o IMC pela fórmula peso / altura².
- Apresenta classificação e destaca a faixa correspondente em uma tabela de referência para adultos.
- Permite limpar o formulário e reiniciar o resultado.

## Tecnologias
- HTML5.
- JavaScript para validação, cálculo e atualização dinâmica.
- Tailwind CSS via CDN.
- Font Awesome.
- Fonte Inter via Google Fonts.

## Resultados e aprendizados
Prática de manipulação de formulários, validação de entradas, conversão de unidades de altura, operações matemáticas e atualização dinâmica de conteúdo na interface.
