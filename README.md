## Resumo dos projetos

- **AT1 — Livraria Página Viva:** site com páginas Início, Sobre, Produtos, Eventos e Contato, folha de estilos própria, JavaScript para destacar a página atual e retorno demonstrativo no formulário.
- **AT2 — FitLife Academia:** site publicado no GitHub Pages, com páginas Início, Sobre, Planos e Produtos, Aulas e Eventos e Contato.
- **AT3 — Calculadora de IMC:** recebe peso e altura, aceita vírgula ou ponto decimal e altura em metros ou centímetros, valida os dados e apresenta classificação para adultos.
- **AT4 — Mente Saudável:** site educativo sobre saúde mental e bem-estar, organizado em cinco páginas e desenvolvido com HTML, CSS e Bootstrap 5.3.3.
- **AT5 — Expatriados de Sofá:** projeto colaborativo sobre solidão e trabalho remoto internacional, com gráfico, quiz interativo, modo claro/escuro e documentação de uso de IA.
