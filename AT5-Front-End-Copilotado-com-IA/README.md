# AT5 — Expatriados de Sofá: Front-End Copilotado com IA

## Descrição
Projeto acadêmico colaborativo sobre solidão, pertencimento e os efeitos socioemocionais do trabalho remoto internacional em jovens desenvolvedores brasileiros.

## Funcionalidades
- Página inicial com apresentação do tema e indicadores.
- Gráfico em Chart.js para comparar relatos de solidão por regime de trabalho.
- Quiz interativo de três perguntas.
- Alternância entre tema claro e escuro, com preferência armazenada no navegador.
- Página de transparência com fontes, metodologia e limites dos dados.
- Página de contato e perfis dos colaboradores.
- Relatório de auditoria do uso de IA.

## Tecnologias utilizadas
HTML5, CSS3, JavaScript, Bootstrap 5.0.2, Chart.js 4.4.3, Google Fonts (Montserrat) e LocalStorage.

## Colaboração
Conforme o README do repositório compartilhado, Renato (@rrenatodevs) ficou responsável pela arquitetura HTML, Design System e integração do Bootstrap; Alexsander (@alexsander1997ribeiro), pela lógica JavaScript, integração com Chart.js e documentação.

## Resultados e aprendizados
Integração de estrutura, estilos e comportamento em páginas estáticas interligadas; interações com JavaScript; visualização de dados; persistência de preferências no navegador; colaboração e documentação de copilotagem.

## Uso responsável de IA
O projeto inclui `AUDITORIA_IA.md`, que registra objetivos, prompts, resultados aplicados e validação humana. Consulte o relatório para os detalhes.
