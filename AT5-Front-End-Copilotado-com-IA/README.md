# AT5 — Front-End Copilotado com IA: Expatriados de Sofá

Projeto acadêmico colaborativo sobre solidão, pertencimento e os efeitos socioemocionais do trabalho remoto internacional em jovens desenvolvedores brasileiros.

## Acessos

- **Repositório do projeto:** https://github.com/rrenatodevs/Projeto-em-Dupla
- **Demonstração publicada:** https://rrenatodevs.github.io/Projeto-em-Dupla/

## Funcionalidades e estrutura

- Página inicial com apresentação do tema e indicadores.
- Gráfico de barras com Chart.js para comparar relatos de solidão por regime de trabalho.
- Quiz de três perguntas com resultado orientativo sobre equilíbrio e isolamento digital.
- Alternância entre tema claro e escuro, com preferência salva no `localStorage`.
- Página de transparência com fontes, metodologia e limites dos dados.
- Página de contato com formulário demonstrativo e perfis dos colaboradores.
- Relatório `AUDITORIA_IA.md` com prompts, resultados, validação e aprendizado.

## Tecnologias identificadas

HTML5 semântico, CSS3 com variáveis, JavaScript, Bootstrap 5.0.2, Chart.js 4.4.3 e Google Fonts.

## Colaboração

O README do repositório atribui a Renato (@rrenatodevs) a arquitetura HTML, o Design System e a integração do Bootstrap; e a Alexsander (@alexsander1997ribeiro) a lógica JavaScript, integração com Chart.js e documentação. Trata-se de um projeto em dupla, mantido no repositório compartilhado.

## Uso responsável de IA

O projeto mantém um relatório de auditoria do uso de IA. As sugestões devem ser revistas, testadas e compreendidas pelos integrantes; o documento de auditoria registra os prompts e a validação humana.
