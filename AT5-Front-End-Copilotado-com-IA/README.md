# AT5 — Front-End Copilotado com IA

## Objetivo
Atividade de desenvolvimento front-end com apoio de ferramentas de inteligência artificial.

## Aplicações possíveis da IA no processo
- Apoiar o planejamento da interface.
- Sugerir estruturas HTML e estilos CSS.
- Auxiliar na análise de erros e melhorias.
- Ajudar a documentar decisões de desenvolvimento.

## Uso responsável de IA
As sugestões geradas por IA devem ser avaliadas criticamente, adaptadas e testadas. O estudante deve compreender o código utilizado e assumir responsabilidade pelo resultado final.
