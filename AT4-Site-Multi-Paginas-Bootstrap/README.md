# AT4 — Site multipáginas com Bootstrap

## Projeto: Mente Saudável

Site educativo sobre saúde mental e bem-estar. O conteúdo está distribuído em cinco páginas:

- **Início:** apresentação do tema.
- **Sobre:** conteúdo informativo sobre saúde mental.
- **Galeria:** cards com dicas e hábitos relacionados ao bem-estar.
- **Dados:** tabela e perguntas frequentes.
- **Contato:** formulário para mensagens.

## Tecnologias
- HTML5.
- CSS.
- Bootstrap 5.3.3.
- JavaScript do Bootstrap para componentes interativos.

## Aprendizados
Organização de um site com múltiplas páginas, navegação, componentes responsivos, cards, tabelas, accordion, modal e formulário.

## Uso responsável de IA
A IA pode apoiar a documentação e o desenvolvimento, mas o autor deve revisar, testar e compreender o código e o conteúdo utilizados na entrega.
