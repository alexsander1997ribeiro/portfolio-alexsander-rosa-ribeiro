# AT4 — Mente Saudável: Site multipáginas com Bootstrap

## Descrição
Site educativo sobre saúde mental e bem-estar, organizado em cinco páginas: início, sobre, galeria, dados e contato.

## Tecnologias utilizadas
- HTML5 e CSS.
- Bootstrap 5.3.3.
- JavaScript do Bootstrap para componentes interativos.

## Resultados e aprendizados
Organização de conteúdo em páginas independentes, navegação entre seções, layout responsivo e utilização de cards, tabelas, accordion, modal e formulário.

## Uso responsável de IA
A documentação de origem recomenda revisão, testes e compreensão humana do código e do conteúdo apoiados por IA. Não há registro detalhado de prompts nesta atividade; não atribuo ferramentas ou contribuições específicas sem evidência.
