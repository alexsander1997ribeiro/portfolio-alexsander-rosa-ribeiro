# AT2 — Deploy de Site: FitLife Academia

## Descrição
Site institucional multipáginas para uma academia fictícia. Reúne páginas de apresentação, informações institucionais, planos e produtos, eventos e contato. O projeto está publicado pelo GitHub Pages.

## Tecnologias e recursos
- HTML5.
- CSS incorporado às páginas HTML.
- Navegação entre páginas, menus e links para seções.
- Cards de planos e produtos, tabela de horários e formulário de contato.

## Resultados e aprendizados
Prática de estruturação de site com várias páginas, organização de conteúdo, navegação, apresentação de informações em cards e tabelas e publicação de um projeto estático na web.
