# AT1 — Páginas HTML

## Objetivo
Atividade voltada à criação e estruturação de páginas para a web utilizando HTML.

## Conceitos trabalhados
- Estrutura de documentos HTML.
- Organização de títulos, parágrafos, imagens e links.
- Navegação entre páginas.
