# AT1 — Páginas HTML: Livraria Página Viva

## Descrição
Site institucional fictício de uma livraria de bairro. O pacote original contém cinco páginas HTML: início, sobre, livros, eventos e contato.

## Tecnologias
- HTML5.
- CSS próprio em `css/style.css`, com variáveis de cores, tipografia e regras de layout responsivo.
- JavaScript em `js/script.js` para destacar a página atual no menu e exibir uma confirmação demonstrativa no envio do formulário.
- Imagens locais originalmente fornecidas na pasta `image/`.
- Fontes Fraunces e Inter via Google Fonts.

## Resultados e aprendizados
Prática de navegação entre páginas, organização de conteúdo, criação de catálogo, agenda de eventos, formulário de contato e estilização compartilhada por uma folha CSS.
