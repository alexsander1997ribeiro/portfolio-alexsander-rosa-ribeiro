# AT1 — Páginas HTML: Livraria Página Viva

Site institucional fictício de uma livraria, recebido no arquivo compactado `Trabalho 01.7z`.

## Páginas

- `index.html` — página inicial e apresentação da livraria.
- `sobre.html` — informações sobre a livraria e sua equipe.
- `produtos.html` — catálogo de livros.
- `eventos.html` — agenda de clubes de leitura, lançamentos e oficinas.
- `contato.html` — endereço, horário de funcionamento e formulário.

## Tecnologias e recursos identificados

- HTML5 para estruturar as cinco páginas.
- CSS próprio em `css/style.css`, com variáveis de cores, tipografia e regras de layout.
- JavaScript em `js/script.js` para destacar o link da página atual e apresentar uma confirmação demonstrativa no envio do formulário.
- Imagens locais referenciadas pela pasta `image/`.
- Fontes Fraunces e Inter carregadas pelo Google Fonts.

## Como executar

Mantenha a estrutura de diretórios original e abra `index.html` em um navegador. Para visualizar corretamente as imagens, a pasta `image/` do arquivo original deve permanecer ao lado dos arquivos HTML.

> Observação: o pacote recebido contém também os arquivos de imagem. Esta documentação registra a estrutura e os recursos encontrados; os links de acesso ao projeto ficam no portfólio.
